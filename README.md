# DemoMapDB（近隣店舗の検索デモ）

音声認識システムとの連携を想定した、コールセンター向けの**近隣店舗案内**デモアプリです。通話中に聞き取った住所をコマンドの引数で渡すと、登録済みの店舗から近い順に N 件を返し、開いている画面の地図にも反映されます。

- 配布物は **`dist\DemoMapDB.exe` の1ファイルだけ**（約140KB）。インストール不要、DLL不要。
- Windows 10 / 11 に標準で入っている .NET Framework 4.8 で動くため、配布先に追加インストールは不要です。
- 店舗の項目（カラム）は**画面から自由に定義**できます。増やした項目は、入力欄・一覧の列・CSVの列・コマンドの変数名に同時に増えます。
- 項目に「営業時間」の型を付けておくと、**現在時刻に営業している店舗だけ**を検索できます。
- データは exe と同じフォルダの `demomapdb_data.xml` に自動保存されます（書き込めない場所では `%LOCALAPPDATA%\DemoMapDB\`）。

```
音声認識システム ──(通話中にコマンド実行)──> DemoMapDB.exe --near "東京都港区芝公園4-2-8" -n 3
                                                    │
                                      住所を緯度経度に変換 → 近い順に並べ替え
                                      標準出力にCSV（JSON/テキストも可）＋ 開いている画面の地図へ反映
```

## 画面

| 画面 | できること |
|---|---|
| 店舗管理（`F7`） | 店舗の登録・編集・削除、絞り込み、CSVの取り込み・書き出し、地図で見る |
| 地図（`F8`） | 検索地点（赤い十字）と近い店舗のピンを番号付きで表示。左の一覧と連動 |
| 項目の設定（`F4`） | 店舗の項目を追加・編集・削除・並べ替え。型・選択肢・キー項目・必須をここで決める |
| CSVを貼り付けて取り込む（`Ctrl+Shift+I`） | Excel などからコピーした表を貼り付け、**取り込まれる内容を確認してから**登録 |
| 連携コマンドのテスト（`F2`） | 音声テキストから取り出した住所で検索を試し、標準出力とコマンドを確認 |
| コマンドラインの使い方（`F1`） | オプション一覧と、いま定義されている項目の変数名 |

主なショートカット: `Ctrl+F` 住所欄へ / `Ctrl+N` 店舗を追加 / `Ctrl+I` CSVファイルを取り込む / `Ctrl+Shift+I` CSVを貼り付け / `Ctrl+E` CSV書き出し / `F5` 再読み込み

コマンドラインで検索されると、**開いている画面に約1.2秒で反映**され、地図の画面に切り替わって前面に出ます。

### 地図について

地図画像は使わず、緯度経度をそのまま平面に置いて描く簡易地図です（表示中心の緯度で経度方向を縮める正距円筒図法）。数十kmの範囲なら距離の見た目はほぼ正しく、**完全オフラインで動きます**。

- ホイールで拡大縮小 / ドラッグで移動 / ダブルクリックで全体表示
- ピンにカーソルを合わせると、店舗の情報と検索地点からの距離・方角を表示
- 検索地点を中心に、距離の目安の同心円と縮尺バーを表示

## 店舗の項目（カラム）

**固定**（地図に必要なため、項目としては消せません）: 店舗名 / 住所 / 緯度 / 経度

このうち**店舗名と住所は、表示名と変数名だけ変えられます**（［項目の設定］で選んで［編集］）。たとえば表示名を「拠点名」、変数名を `shop_name` にすると、画面の見出し・CSVの見出し・`--set shop_name=…`・JSONのキーがまとめて変わります。緯度・経度は固定です。

**自由に定義できる項目**（初期状態）:

| 表示名 | 変数名 | 型 | 一覧・標準出力 | キー項目 |
|---|---|---|---|---|
| 店舗コード | `code` | テキスト | | ○ |
| 電話番号 | `phonenumber` | 電話番号 | | |
| 営業時間 | `businesshours` | 営業時間 | | |
| 備考 | `memo` | 長文テキスト | | |

- **型**: テキスト / 長文テキスト / 電話番号 / **営業時間** / URL / 数値 / 日付 / 選択リスト / チェックボックス
- **一覧・標準出力**: 一覧の列と、検索結果CSVに含める項目。**1つも指定しないと、先頭から3つ**が使われます（初期状態は指定なしなので、店舗コード・電話番号・営業時間が出ます）
- **キー項目**: 1つだけ指定できます。同じ値の店舗があれば更新、無ければ新規登録（通話中に複数回送っても1件にまとまります）
- **営業時間の型**: `9:00-21:00` のような値を時刻として読み、営業時間でのしぼり込みに使います（下記）
- 変数名は `--set 変数名=値` や環境変数名に使います。`--fields` でいつでも確認できます。

## 営業時間でのしぼり込み

型を「営業時間」にした項目の値を、指定した時刻と突き合わせます。画面では検索バーの **［営業時間内のみ］**、コマンドでは `--open-now`（現在時刻）/ `--open-at 18:30`（指定時刻）です。地図画面の結果一覧には「営業」列が出ます。

書ける形:

| 書き方 | 意味 |
|---|---|
| `9:00-21:00` | その時間帯だけ営業 |
| `11:00-14:00, 17:00-22:00` | 中休みあり（`,` `、` `/` 空白で区切る） |
| `18:00-2:00` | 日をまたぐ（終わりが始まりより前なら翌日扱い） |
| `24時間` / `終日` / `年中無休` | 常に営業 |
| `定休日` / `休業` | 常に営業時間外 |
| 空欄・読めない値 | **不明として、しぼり込みでは除外しません**（取りこぼしを避けるため） |

`〜` `～` `：` などの全角、`9時` の表記、`10:00-20:00（L.O.19:30）` のようなカッコ書きも読めます。

※ デモ用のため、**曜日ごとの営業時間や祝日は見ていません**。曜日別に持ちたい場合は「平日」「土日」など項目を分け、しぼり込み（`-w`）と併用してください。

## データの投入（CSV）

取り込み方は2通りあります。どちらも**1行目が見出し**で、列の並び順は自由、要らない列は省けます。

1. **CSVファイル**: ［ファイル］→［CSVファイルを取り込む…］（`Ctrl+I`）、またはコマンドの `--import`
2. **貼り付け**: ［ファイル］→［CSVを貼り付けて取り込む…］（`Ctrl+Shift+I`）。Excel からのコピー（タブ区切り）もそのまま貼れます。［内容を確認］で**新規/更新の別と取り込まれる値を一覧**してから取り込めます

```csv
店舗名,住所,店舗コード,電話番号,営業時間,備考,緯度,経度
新宿三丁目店,東京都新宿区新宿3-1-1,T101,03-0000-0000,10:00-21:00,,,
```

列は「店舗名・住所（設定した表示名）＋項目の表示名＋緯度・経度」です。

- 緯度・経度が空なら、**取り込んだあとに住所から自動で取得**します（コマンドでは `--no-geocode` で抑止）。
- 見出しは表示名・変数名のほか、`name` `address` `phone` `lat` `lng` などの別名でも読めます。
- キー項目（既定は店舗コード）が一致する店舗があれば更新します。**キー項目が空の行は毎回새規追加**になります。
- 文字コードは UTF-8 / UTF-8（BOM付き）/ Shift_JIS を自動判別します。

## 住所 → 緯度経度の変換

次の順に試し、最初に決まったものを使います。

1. `35.658,139.745` のような**緯度経度の直接指定**
2. **国土地理院の住所検索API**（キー不要・無料。番地まで正確。既定で有効、`--offline` や［設定］メニューで無効化可）
3. **内蔵の住所表**（都道府県と主な市区町村の代表点、約190件）と**登録済み店舗の住所**のうち、いちばん長く一致したもの

3 は完全オフラインで動きますが、番地までの精度は出ません（誤差は数百m〜数km）。「大阪市北区梅田」のように都道府県が省かれた住所にも対応しています。

## コマンドライン（他システム連携）

### 検索

```bash
DemoMapDB.exe --near "東京都港区芝公園4-2-8" -n 3
```

```csv
順位,店舗名,距離,方角,住所,店舗コード,電話番号,営業時間
1,東京タワー前店,10m,南西,東京都港区芝公園4-2-8,T001,03-3433-5111,9:00-21:00
2,新橋駅前店,1.4km,北東,東京都港区新橋2-16-1,T002,03-3571-0101,10:00-20:00
3,六本木ヒルズ店,1.5km,西,東京都港区六本木6-10-1,T004,03-6406-6000,11:00-21:00
```

標準エラー出力に `検索地点: 東京都港区芝公園四丁目２番（国土地理院の住所検索 35.65865,139.74547）` が出ます（`-q` で抑止）。

| オプション | 内容 |
|---|---|
| `-n, --count <件数>` | 表示する件数（既定 3） |
| `-r, --radius <km>` | この距離までにしぼる（既定 上限なし） |
| `-w, --where <変数名>=<値>` | 項目でしぼる（部分一致。複数指定可。表示名でも可） |
| `-k, --keyword <語>` | 店舗名・住所・自由項目の部分一致でしぼる |
| `--open-now` | いま営業時間内の店舗だけにしぼる |
| `--open-at <時刻>` | その時刻に営業している店舗だけにしぼる（例: `18:30`） |
| `--json` / `--text` | 出力の形を変える（既定は CSV） |
| `--full` | CSVに全項目・距離km・緯度経度も出す |
| `--latlon "35.65,139.74"` | 住所の代わりに緯度経度を直接渡す |
| `--offline` / `--online` | オンライン検索を使わない／必ず使う |
| `--timeout <ミリ秒>` | オンライン検索の待ち時間（既定 4000） |
| `--no-gui` | 開いている画面へ反映しない |
| `--strict` | 該当店舗なし・住所を特定できないときの終了コードを 1 / 2 にする（既定は 0） |
| `--encoding <文字コード>` | `utf8` / `utf8bom` / `sjis` |

`--json` の出力（音声認識システム側で読みやすい形。自由項目は変数名のキーで入ります）:

```json
{"status":"ok","count":1,"query":"...","matched":"...","source":"online","origin":{"lat":35.45666,"lng":139.63402},
 "stores":[{"rank":1,"name":"横浜みなとみらい店","address":"...","distance_km":0.225,
            "distance_text":"230m","direction":"西","lat":35.4574,"lng":139.6317,
            "code":"Y001","phonenumber":"045-222-1111","businesshours":"10:00-21:00","memo":""}]}
```

### 店舗の登録・更新

```bash
DemoMapDB.exe --add --name "新宿三丁目店" --store-address "東京都新宿区新宿3-1-1" --set code=T101 --set phonenumber=03-0000-0000 --set businesshours="10:00-21:00"
```

```text
登録しました（店舗ID:22 新宿三丁目店 35.68967,139.70627）
```

- 住所から緯度経度を自動取得します（`--no-geocode` で抑止、`--store-latlon "35.6,139.7"` で直接指定）。
- **キー項目（既定は店舗コード）が同じ店舗があれば更新**します。
- `--set` は省略して `code=T101` と書いてもかまいません。定義されていない変数名は無視し、警告を標準エラー出力に出します。
- 店舗名・住所も `--set name=○○店` `--set address=東京都…`（設定した変数名・表示名）で渡せます。

### そのほか

| コマンド | 内容 |
|---|---|
| `--fields` | 定義されている項目を一覧（変数名の確認用） |
| `--list [-k <語>] [-w 変数名=値]` | 登録店舗をCSVで出力 |
| `--import <CSVファイル>` / `--export <CSVファイル>` | 取り込み・書き出し |
| `--fill` | 緯度経度が空の店舗を住所から埋める |
| `--geocode "<住所>"` | 住所の変換結果だけを確認する |
| `--sample` | デモ用のサンプル店舗（21件）を投入（はじめて画面を開いたときにも自動で入ります） |
| `--data <ファイル>` | 使うデータファイルを指定 |

### 環境変数からの取り込み

音声認識システムが環境変数で値を渡す場合に使います。

```bash
DemoMapDB.exe --env-prefix
```

| 環境変数 | 対応 |
|---|---|
| `AMIVOICE_ST_ADDRESS` | 検索する住所 |
| `AMIVOICE_ST_COUNT` / `_RADIUS` / `_KEYWORD` | 件数 / 半径 / キーワード |
| `AMIVOICE_ST_<変数名（大文字）>` | 検索では項目のしぼり込み、`--add` では項目の値（例 `AMIVOICE_ST_CODE`） |
| `DEMOMAPDB_DATA` | データファイルの場所（`--data` でも指定可） |
| `DEMOMAPDB_LOG` | 実行ログの場所（`off` で無効） |

接頭辞は `--env-prefix 別の接頭辞_` で変えられます（既定 `AMIVOICE_ST_`）。

### 出力先とエラー

- **標準出力**には結果だけを書きます（CSV / JSON / テキスト、登録メッセージ）。
- **標準エラー出力**には、エラーと補足（`検索地点: …`、無視した項目の警告）を書きます。
- **エラーメッセージは `-q` を付けても出ます**。`-q` が抑えるのは `検索地点: …` の補足行だけです。

#### 終了コード

**「該当する店舗がない」「住所を特定できない」は通常の運用でも起こるので、既定では終了コード 0 で返します**（連携側でプロセスの異常終了と扱われないようにするため）。異常終了とするのは、呼び出しの誤りや想定外の例外（9）だけです。

| コード | 意味 |
|---|---|
| 0 | 正常終了（該当店舗が0件のとき、住所を特定できなかったときも含む） |
| 9 | 呼び出しの誤り（オプションの誤りなど）・想定外の例外 |

0件のときも**標準出力は空にせず**、呼び出し側が中身で判別できる形で返します。

| 形式 | 0件のときの標準出力 |
|---|---|
| CSV（既定） | 見出しの行だけ（データ行なし） |
| `--json` | `{"status":"no_store","count":0,...,"stores":[]}` |
| `--text` | 何も出しません |

`status` は `ok`（正常）/ `no_store`（該当店舗なし）/ `no_address`（住所を特定できない）。正常時も `status` と `count` が入ります。

`--strict` を付けると、従来どおり **1 = 該当店舗なし / 2 = 住所を特定できない** を返します（終了コードで分岐したい場合に使ってください）。

#### 状況ごとの出力

| 状況 | 終了コード | 標準出力 | 標準エラー出力 |
|---|---|---|---|
| 正常 | 0 | 結果 | `検索地点: 東京都港区芝公園四丁目２番（国土地理院の住所検索 35.65865,139.74547）` |
| 住所が空（`--near ""`、空白のみ、`AMIVOICE_ST_ADDRESS` が空） | 0（`--strict` で 2） | 見出しのみ / 空JSON | `住所が指定されていません（--near "東京都港区芝公園4-2-8"）` |
| 住所から場所を特定できない | 0（`--strict` で 2） | 見出しのみ / 空JSON | `住所から場所を特定できませんでした: ぬるぽがっ` |
| 条件に合う店舗が0件（半径・しぼり込みの結果など） | 0（`--strict` で 1） | 見出しのみ / 空JSON | `該当する店舗がありません` |
| オプションの値がない | 9 | なし | `--near の値がありません` |
| 知らないオプション | 9 | なし | `不明なオプション: --nearby` |
| 件数・半径が不正 | 9 | なし | `件数は1以上の数で指定してください: 0` |
| `--latlon` の形式ミス | 9 | なし | `--latlon は 緯度,経度 の形で指定してください（例: 35.65858,139.74543）: 35.6` |
| `--add` で店舗名がない | 9 | なし | `店舗名を指定してください（--name "○○店"）` |
| 取り込むCSVがない | 9 | なし | `ファイルがありません: C:
ope
ope.csv` |
| 想定外の例外 | 9 | なし | `エラー: <内容>` |
| 引数なしで起動 | ― | ― | ―（画面が開きます） |
| `--help` / `/?` | 0 | 使い方 | なし |

**警告（処理は続けます。終了コードは 0）**

| 状況 | 標準エラー出力 |
|---|---|
| 知らない項目でしぼり込み | `知らない項目なので無視します: 担当` |
| `--set` に定義されていない変数名 | `定義されていない項目なので無視します: tantou（--fields で確認できます）` |
| CSVに知らない列がある | `知らない列は読み飛ばします: <列名>` |
| CSVの緯度経度が読めない | `12行目: 緯度経度を読めませんでした（○○店）` |

オンライン住所検索が失敗したとき（ネットが無い・タイムアウト・APIが応答しない）は、**エラーにせず内蔵の住所表に切り替えて**続けます。`検索地点: …` の `（取得元）` で、どちらで決まったかが分かります。

呼び出し側の例（バッチ。終了コードは 0 か 9 だけを見て、内容は出力で判別）:

```bat
DemoMapDB.exe --near "%AMIVOICE_ST_ADDRESS%" -n 3 -q --json > result.json
if errorlevel 1 goto CALL_ERROR
rem 正常終了。result.json の "status" が ok / no_store / no_address
```

実行ごとに、データファイルと同じフォルダの `demomapdb_log.txt` へ1行（日時・終了コード・処理時間・結果・引数）記録します。「該当なし」「住所を特定できない」も、終了コードとは別にここへ結果として残るので、あとから追えます。

## ビルド

```bash
build.bat
```

Windows に入っている C# コンパイラ（`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`）でビルドします。SDK もプロジェクトファイルも要りません。

| ファイル | 役割 |
|---|---|
| `src\Program.cs` | 起動（引数あり→コマンドライン、なし→画面） |
| `src\Data.cs` | 店舗・項目定義のモデルと保存 |
| `src\Hours.cs` | 営業時間の文字列を読んで、その時刻に営業しているか判定 |
| `src\Geo.cs` | 距離・方位の計算、住所→緯度経度（オンライン／内蔵の住所表） |
| `src\Search.cs` | 近い順の検索、CSV/JSON/テキスト出力、画面への受け渡し |
| `src\Cli.cs` | コマンドラインと実行ログ |
| `src\MapPanel.cs` | 簡易地図の描画と操作 |
| `src\MainForm.cs` | 店舗管理・地図の2画面 |
| `src\Dialogs.cs` | 店舗の編集、CSV貼り付け、使い方、連携テスト |
| `src\Fields.cs` | 項目の設定 |
| `src\Import.cs` | CSVの読み書き |
| `src\Theme.cs` / `src\Settings.cs` | ライト・ダークの配色、PCごとの設定 |
